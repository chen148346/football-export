# DESIGN.md

## 项目与用户画像
- 足球比赛数据报表导出模块（内部工具），为数据分析提供 Excel 训练/报表数据。
- 用户为主要使用者（非对外），界面追求稳定、直观、低学习成本，强调与 V1.7 原有界面风格一致。

## 视觉与布局策略
- 沿用现有导出页面的界面语言：顶部蓝色标题栏 + 版本徽标、分区卡片（筛选条件 / 导出设置 / 操作与反馈 / 数据库信息）、`export.css` 相应样式。
- 新增"固定表头导出"作为独立功能页面/分区，与 V1.7 并存，不互相干扰。

## Design Tokens（沿用现有）
### 色彩
- 主色蓝：`#4472C4`（表头背景、主按钮主色）
- 表头文字：白 `#FFFFFF`；浅灰文字 `#666`
- 表格边框浅灰：`#D9D9D9`

### 字体
- 界面/表格字体：微软雅黑（Microsoft YaHei）
- 表头：11px 加粗；数据：10px

### 布局
- 表头冻结首行、自动列宽（中文字符按 2 宽计）

## 数据与文案规范
- **统一简体中文字段名**：所有 sheet 表头与字段值统一使用简体中文（如"控球率"而非繁体），乱码/生僻变体归一化。
- **固定表头原则**：8 个 sheet 表头固定不变，场次缺失字段留空（不动态增列）。
- **球队名标准化**：优先用球队 ID 锚定（`homeTeam.id`/`awayTeam.id`），同一球队翻译变体归一到规范名；无 ID / 未收录时回退原始名。
- **空缺填充**：留空字符串，不做占位。

## 交互与状态
- 导出为异步任务，前端轮询进度，与 V1.7 一致。
- 校验信息、结果反馈样式复用现有组件。
